### 1. Google 发布 SL2T 手语 AI，首次装进 Pixel 11 手机
- 来源：Google DeepMind / SiliconANGLE
- 链接：https://deepmind.google/blog/putting-sign-language-ai-into-users-hands/
- 这件事是什么：8 月 12 日，Google DeepMind 发布手语转文字模型 SL2T，首次在 Pixel 11 的 Gboard 键盘和 Live Transcribe 中上线。聋人或听障用户可以用美国手语（ASL）直接搜索、写消息、跟 Gemini 对话。处理在本地完成，只上传几何坐标，不上传原始视频。
- 为什么重要：这是全球第一款真正装进消费级产品的手语 AI，不是实验室 Demo。Google 还成立了手语 AI 顾问委员会，跟聋人组织一起制定发布规范。目前只支持 ASL 转英文，更多语言和手语生成在规划中。
- 对我有什么影响：如果你或身边的人是听障用户，Pixel 11 可能是目前最实用的手语输入设备。对开发者来说，这是无障碍 AI 从研究走向产品的标杆案例，值得关注本地推理和隐私保护的设计思路。

### 2. Google 发布 Pixel 11 系列，Tensor G6 芯片让端侧 AI 快 3.5 倍
- 来源：SiliconANGLE
- 链接：https://siliconangle.com/2026/08/12/google-launches-five-new-pixel-devices-array-gemini-intelligence-features/
- 这件事是什么：8 月 12 日，Google 一口气发布 5 款 Pixel 设备，包括 Pixel 11 系列手机和 Pixel Watch 5。全系搭载自研 Tensor G6 芯片，内置 AI 加速器算力比上代提升 50%，跑端侧模型速度提升 3.5 倍、功耗更低。手表新增 Gemini 主动建议功能，能自动从 App 里抓取信息展示。
- 为什么重要：Google 把「AI 手机」从营销口号变成硬件标配。Tensor G6 的意义在于：越来越多 AI 功能可以不联网、不上云，直接在手机里跑。这跟 Apple Intelligence、华为端侧大模型的路线一致，端侧 AI 竞争进入硬件比拼阶段。
- 对我有什么影响：如果你考虑换安卓手机且重度用 Gemini，Pixel 11 的端侧 AI 体验会是目前 Google 生态里最好的。对普通用户，感知可能是「手机更聪明、反应更快」；对开发者，端侧模型部署的硬件门槛在持续降低。

### 3. 三大 AI 厂商推理链加密被攻破，GitHub 上泄露 182 条密钥
- 来源：Decrypt / arXiv
- 链接：https://decrypt.co/375501/inner-thoughts-every-major-ai-model-exposed-exploit
- 这件事是什么：8 月 10 日，安全研究团队发表论文，发现 OpenAI、Anthropic、Google 三家都用同一个全局加密密钥保护「推理链」（AI 思考过程的加密文本块）。攻击者可以把强模型的加密思考注入弱模型，逼它解密并输出明文。团队从公开的 GitHub 日志中解码了 31.5 万个推理块，挖出了 62 个有效 API 密钥和 33 个密码。
- 为什么重要：推理链加密本来是保护模型知识产权和用户隐私的，结果因为架构设计缺陷变成了「一把钥匙开所有门」。三家厂商已在负责任披露后打了补丁，但已经公开分享过的历史日志仍然可以被解码。
- 对我有什么影响：如果你用 AI 编程工具并把对话日志公开到 GitHub，赶紧检查有没有包含加密的 reasoning 块，里面可能藏着 API 密钥。以后分享 AI 对话记录要更谨慎，别把完整 session log 直接贴出去。

### 4. DeepSeek V4 Pro 正式版（0813）发布，旗舰模型结束预览期
- 来源：Unite.AI / DeepSeek API 文档
- 链接：https://www.unite.ai/zh-cn/deepseek-ships-v4-pro-as-its-flagship-model-leaves-preview/
- 这件事是什么：8 月 12 日，DeepSeek 把旗舰模型 V4 Pro 从预览版升级为正式版，版本号 V4-Pro-0813。上下文窗口 100 万 Token，输出上限 38.4 万 Token，API 定价维持每百万 Token 输入 0.435 美元、输出 0.87 美元。官方仍预告「近期将大幅涨价」，但目前费率不变。
- 为什么重要：DeepSeek 的分阶段发布策略走完了一半：Flash 版负责走量和 Agent 场景，Pro 版负责旗舰能力。正式版意味着 API 稳定性和 SLA 更有保障，适合接入生产环境。结合即将涨价的消息，现在是「最后的低价窗口期」。
- 对我有什么影响：如果你在做产品且依赖 DeepSeek API，建议尽快把 V4 Pro 接入生产环境测试，同时准备涨价后的成本预案。个人用户如果只用网页版，影响不大；开发者要关注官方涨价通知，别等业务跑起来才发现成本翻倍。

### 5. DeepSeek 全面适配华为昇腾 950，阿里腾讯字节抢购国产芯片
- 来源：Reuters / 雅虎财经
- 链接：https://hk.finance.yahoo.com/news/%E7%B4%9B%E7%B4%9B%E6%90%B6%E8%B3%BC-deepseek%E6%96%B0%E6%A8%A1%E5%9E%8B%E5%85%A8%E7%94%A8%E8%8F%AF%E7%82%BA%E6%99%B6%E7%89%87-%E5%BC%95%E7%99%BC%E9%98%BF%E9%87%8C%E9%A8%B0%E8%A8%8A%E5%AD%97%E7%AF%80%E7%AD%89%E6%90%B6%E8%B3%BC%E6%98%87%E9%A8%B0950%E7%B3%BB%E5%88%97ai%E6%99%B6%E7%89%87-034937588.html
- 这件事是什么：据报道，DeepSeek V4 新模型全面基于华为昇腾 950 系列芯片训练和推理，性能优于被禁的 Nvidia H20，引发阿里巴巴、腾讯、字节跳动等大厂纷纷联系华为洽谈芯片采购。华为计划今年出货约 75 万颗昇腾 950PR，4 月已开始量产。
- 为什么重要：这是中国 AI 产业链「去美国化」的关键一步。DeepSeek 从「用 Nvidia 芯片做出好模型」转向「用国产芯片做出好模型」，直接带动了整条国产算力链的需求。在 H200 仍被卡脖子的情况下，昇腾 950 成了国内大厂的务实选择。
- 对我有什么影响：如果你在国内做 AI 业务，算力采购策略可能要调整——Nvidia 不再是唯一选项。对投资者，华为昇腾生态和配套软件（CANN、MindSpore）值得关注。普通用户短期无感，但国产 AI 的成本和可用性会因此改善。

### 6. DeepSeek Harness 团队亮相，瞄准 Agent 工程化「让模型跑起来」
- 来源：数据宝 / 网易
- 链接：https://www.163.com/dy/article/L45KSOVU0517BMJU.html
- 这件事是什么：8 月 12 日，DeepSeek 旗下「Harness 团队」微信公众号完成注册，头像为黑色鲸鱼。Harness 是模型之外的工程化层，负责工具调用、任务编排、失败恢复等，类似 OpenAI 的 Codex 和 Anthropic 的 Claude Code。团队 5 月立项，负责人在全球征集内测开发者。
- 为什么重要：2026 年最大的商业化机会不是模型本身，而是 Harness——谁能让模型稳定地完成复杂任务，谁就掌握用户。DeepSeek 单独成立团队说明他们也认清了这一点。结合 V4-Flash 在全球 OpenRouter 调用量第一的成绩，DeepSeek 正在从「模型公司」变成「Agent 平台公司」。
- 对我有什么影响：如果你有 Agent 或开源 Harness 项目经验，可以关注 DeepSeek 的内测招募。如果你在做 AI 产品，别只盯着选哪个模型，更要关注编排层怎么设计——这才是决定用户体验的关键。

### 7. Nvidia 发布 Nemotron 3.5 Lightning 开源模型 + Switchyard 路由框架
- 来源：MarkTechPost / The Next Web
- 链接：https://www.marktechpost.com/2026/08/11/nvidia-ai-releases-nemotron-3-5-lightning-and-nemo-switchyard/
- 这件事是什么：8 月 11-12 日，Nvidia 发布 300 亿参数开源 MoE 模型 Nemotron 3.5 Lightning（每次激活 30 亿参数），支持 100 万 Token 上下文，专为 Agent 高频任务优化，速度比同类模型快 4 倍。同时发布 NeMo Switchyard 开源路由库，能自动把 Agent 各步骤分配给最合适的模型，成本降到单独用顶级模型的三分之一。
- 为什么重要：Nvidia 不只卖芯片了，开始卖「Agent 系统方案」。Lightning 负责快、便宜的重复任务，Switchyard 负责智能调度，这套组合拳直接对标中国开源模型的性价比优势。据报道，Nvidia 还在开发万亿参数的 Nemotron 4，预计秋季发布。
- 对我有什么影响：如果你在搭建多模型 Agent 系统，Switchyard 值得一试——它可能帮你省下大量 API 费用。Lightning 权重已在 Hugging Face 上线，可以本地部署做代码审查、安全监控等高频任务。对国内开发者，这是又一个高质量开源选项，跟 Qwen、DeepSeek 可以混搭使用。

### 8. AI 编程基础设施融资爆发：CodeRabbit 14.3 亿美元、Blacksmith 5500 万美元估值
- 来源：TechCrunch / CodeRabbit 官方博客
- 链接：https://techcrunch.com/2026/08/12/blacksmiths-valuation-jumps-10x-to-550m-as-ai-coding-fuels-software-validation/
- 这件事是什么：8 月 12 日，AI 代码审查平台 CodeRabbit 完成 1.43 亿美元 C 轮融资，估值 15 亿美元，并推出「Agentic Change Management」新品类。同一天，CI 云基础设施 Blacksmith 融资 4500 万美元 B 轮，估值 5.5 亿美元（不到一年前才 6000 万），客户从 800 家涨到 6000 多家。
- 为什么重要：AI 让写代码变快了，但测试、审查、验证成了新瓶颈。资本市场用真金白银投票：「AI 生成代码之后怎么办」是一个百亿级市场。CodeRabbit 管「代码质量」，Blacksmith 管「跑测试的速度」，两者解决的是同一个痛点。
- 对我有什么影响：如果你用 AI 写代码，建议尽快接入自动化代码审查（CodeRabbit、GitHub Copilot Review 等），别让 AI 生成的代码未经检查就上线。团队如果 CI 跑得很慢，Blacksmith 这类专用 CI 云可以显著提速。对个人开发者，CodeRabbit 承诺未来 12 个月对开源项目免费。
