### 1. Anthropic 与 AI 云初创 Volta 签下 100 亿美元、六年期算力协议
- 来源：TechCrunch / Bloomberg
- 链接：https://techcrunch.com/2026/08/04/anthropic-signs-10-billion-deal-with-ai-cloud-startup-volta/
- 这件事是什么：8 月 4 日，Anthropic 与今年刚成立的 AI 云公司 Volta 签下约 100 亿美元、为期六年的算力合同。数据中心建在挪威，由矿企 Bitdeer 参与开发，总容量 133 兆瓦，将搭载 Nvidia Vera Rubin 芯片。这是 Anthropic 继 SpaceX、亚马逊之后又一笔大额算力扩张。
- 为什么重要：大模型竞争已从「谁模型更强」延伸到「谁有电、有卡、有数据中心」。Anthropic 一边跟白宫谈安全审查，一边疯狂囤算力，说明 Claude 下一代训练/推理需求极大。
- 对我有什么影响：短期内对你用 Claude API 影响不大，但算力扩张通常意味着更强模型和更稳定服务。如果你在比价各家 API，可以关注 Anthropic 是否借此降价或推出更强版本。

### 2. AWS 开源 Kiro Crew：让 AI 编程 Agent 7×24 小时自主干活
- 来源：InfoWorld / SiliconANGLE
- 链接：https://siliconangle.com/2026/08/04/aws-launches-kiro-crew-autonomous-agentic-orchestrator-24-7-code-development/
- 这件事是什么：8 月 4 日，亚马逊 AWS 发布并开源 Kiro Crew——一个持久化的 AI 编程编排平台。它能在你离线时继续跑多 Agent 任务、定时巡检 PR 和工单、跨会话保留项目记忆，还能通过 Slack、Discord、Telegram 远程下达指令。Apache 2.0 协议，代码已上 GitHub。
- 为什么重要：AI 编程工具正从「你问一句它答一句」进化到「你下班它还在写代码」。Kiro Crew 是 AWS 在这个方向上的开源答卷，直接对标 Claude Code、Codex 等 Agent 工作流。
- 对我有什么影响：如果你是开发者，可以本地部署试用，看能不能把重复性工程任务（修 bug、写测试、盯 PR）交给 Agent 后台跑。注意：多 Agent 并行会显著增加 API 调用费用，上线前先把预算和审批流程想清楚。

### 3. Nvidia 开源 cuFile 存储接口，GPU 可直接读写硬盘绕过 CPU
- 来源：NVIDIA Blog / SiliconANGLE
- 链接：https://blogs.nvidia.com/blog/ai-storage-fms/
- 这件事是什么：8 月 4 日在 FMS 存储大会上，Nvidia 宣布开源 cuFile API 及完整垂直存储软件栈，让 GPU 能直接读写存储，不再绕道 CPU 和主内存，数据访问延迟可降到微秒级。Google、Intel、Meta 与 Nvidia 共同担任 XIO-SIG 开源维护方，40 多家存储厂商参与 Storage-Next 倡议。
- 为什么重要：AI 训练和推理越来越吃存储带宽，CPU 成了瓶颈。cuFile 开源意味着存储层也能享受 GPU 并行优势，对大模型训练和 Agent 高频读数据场景是底层提速。
- 对我有什么影响：普通用户短期无感。如果你是做 AI 基础设施、自建训练集群或云存储的工程师，这是值得关注的开源标准——未来买存储设备可能会标注「cuFile 兼容」。

### 4. Nvidia 牵头 OSAA 联盟一周扩至 120 家，SAFE 工作组开始征集安全方案
- 来源：TechCrunch / GamesBeat
- 链接：https://techcrunch.com/2026/08/04/nvidia-doesnt-mess-around-a-week-after-open-ai-industry-group-formed-its-already-showing-progress/
- 这件事是什么：8 月 4 日，Nvidia 牵头的 Open Secure AI Alliance（OSAA）成立仅一周已吸纳 120 多家公司，并启动 SAFE（Shared AI Findings Exchange）工作组，向业界征集 AI Agent 安全方案。成员贡献包括 Nvidia 的 Garak 漏洞扫描器、Amazon 的 Strands Agents 和 Cedar 授权语言、微软的 PyRIT 红队工具等。OpenAI、Anthropic、Google 尚未加入。
- 为什么重要：OpenAI、Anthropic Agent 越狱入侵事件后，行业急需可互操作的安全标准。OSAA 用开源工具快速响应，但头部闭源实验室缺席，标准能否真正落地还有变数。
- 对我有什么影响：如果你在部署企业 Agent，可以关注 OSAA 发布的 SAFE 指南和开源工具，作为安全评估 checklist。8 月 4 日 Black Hat 上还有联盟成员线下碰头，后续方案值得跟踪。

### 5. DeepSeek V4-Flash 登顶全球大模型周调用量榜首，国产模型包揽前五
- 来源：TechWeb / 新浪财经
- 链接：https://news.futunn.com/post/77050689
- 这件事是什么：8 月 4 日，OpenRouter 数据显示，上周（7 月 28 日至 8 月 3 日）DeepSeek V4-Flash 以 7.1 万亿 Token 周调用量登顶全球第一。第二至第五名全是国产：小米 MiMo-V2.5、腾讯 Hy3、DeepSeek V4-Pro、智谱 GLM-5.2。中国模型周调用量 28.13 万亿，连续 14 周超过美国。
- 为什么重要：这是国产大模型首次在实际使用量上全面领先，不靠发布会 PPT，而是开发者真金白银的 API 调用。DeepSeek 用工程优化（Harness 工具 + 后训练）让「小杯」Flash 打败自家「大杯」Pro 预览版，说明算力之外还有杠杆。
- 对我有什么影响：如果你在选 API，DeepSeek V4-Flash 性价比极高（输入约 $0.14/M tokens），适合高频 Agent 和代码场景。国产模型调用量领先也意味着生态工具、文档和社区支持会更跟得上。

### 6. 企业 Agent 平台 HappyRobot 融资 1.5 亿美元，估值 12 亿美元
- 来源：SiliconANGLE / Tech.eu
- 链接：https://siliconangle.com/2026/08/04/happyrobot-raises-150m-1-2b-valuation-bring-ai-agents-critical-enterprise-work/
- 这件事是什么：8 月 4 日，旧金山创业公司 HappyRobot 完成 1.5 亿美元 C 轮融资，估值 12 亿美元，由 Prysm Capital 领投。公司做企业级 AI Agent 基础设施，已服务 DHL、Uber、Repsol 等 150 多家企业，在客服场景实现约 70% 自主解决率。
- 为什么重要：Agent 赛道从「概念演示」进入「规模化商业落地」阶段。HappyRobot 专注物流、能源、电信等复杂运营场景，说明企业愿意为能真正干活的 Agent 付大钱。
- 对我有什么影响：如果你在考虑企业采购 AI Agent 方案，HappyRobot 是值得关注的新晋独角兽。对个人开发者，它的成功说明垂直场景 Agent（客服、调度、运维）比通用聊天更有变现空间。

### 7. Obsidian Security 融资 8500 万美元，专攻 AI Agent 身份与访问安全
- 来源：SiliconANGLE
- 链接：https://siliconangle.com/2026/08/04/obsidian-security-raises-85m-ai-agents-create-cybersecuritys-next-major-attack-surface/
- 这件事是什么：8 月 4 日，云安全公司 Obsidian Security 完成 8500 万美元 D 轮融资，估值 11 亿美元。公司专注治理 AI Agent 访问企业数据时的「非人类身份」安全——Agent 能读代码、调 API、改配置，传统基于人的权限模型管不住。
- 为什么重要：OpenAI、Anthropic Agent 越狱事件证明，攻击面正在从「人」转向「AI 代理」。Obsidian 这类公司押注 Agent 安全是下一个百亿赛道，Rubrik 同期也推出了 Agent Identity 产品。
- 对我有什么影响：如果你在公司负责安全或 IT，部署 Agent 前要先想清楚：这个 Agent 能访问哪些系统？谁审计它的操作？Obsidian、Rubrik 等产品可以作为评估参考，别等出事再补洞。

### 8. 美国 NSF 启动 1 亿美元州级 AI 基础设施中心计划
- 来源：NSF 官网
- 链接：https://www.nsf.gov/news/new-nsf-state-regional-ai-infrastructure-hubs-will-power-ai
- 这件事是什么：8 月 4 日，美国国家科学基金会宣布「州与区域 AI 基础设施中心」计划，总投入 1 亿美元，首批支持最多 10 个区域联盟，为科研人员、学生和教育者提供算力、数据和 AI 培训。Nvidia、AMD、Intel、Dell 等已表示参与支持。
- 为什么重要：AI 科研越来越依赖大规模算力，但资源集中在少数机构和公司手里。这个计划试图把 AI 基础设施下沉到各州，缩小「有算力」和「没算力」的研究差距。
- 对我有什么影响：对国内用户直接影响有限。如果你在美国的大学或研究机构，可以关注所在州是否申请成为 AI 基础设施中心，可能获得算力配额和培训资源。
