# 每日 AI 简报 - 2026-10-25

## 今日最重要的8条 AI 新闻

> 说明：覆盖 UTC 10 月 24 日左右发布或集中解读的报道。昨日简报已写 OpenAI 训练断网、DeepSeek 融资、Wayve 自动驾驶、Google 隐私政策、Anthropic 托管 Claude、MiniMax Design MCP、OpenAI–NASK 合作、Anthropic IPO 节奏等；今日侧重国产新旗舰、语音模型、Agent 基础设施与国内应用层洗牌。

### 1. 月之暗面发布 Kimi K3.1 Pro：3T 级开源路线 + 百万上下文
- 来源：Moonshot AI 官方 / Bloomberg
- 链接：https://www.kimi.ai/blog/kimi-k3-1-pro
- 这件事是什么：10 月 23–24 日，月之暗面推出 K3.1 系列首款 K3.1 Pro，号称最强 3T 级「开放权重」模型之一，上下文 100 万 token，强化编程、3D、金融研究和 Agent；同步有 Highspeed 版本（约 2–3 倍速度）。API 与 Kimi 全系已可用，完整权重承诺 11 月 4 日前公开。
- 为什么重要：在 Claude Opus 5.5、GPT-6 Astra 等闭源旗舰旁边，又一家中国 lab 把「接近顶尖 + 即将开源」摆上台面，直接牵动 API 定价和自托管选择。
- 对我有什么影响：写代码、长文档分析可先上 Kimi API 试跑；若你打算本地部署，盯住 11 月初 Hugging Face 是否放出完整权重。企业版默认未开，需管理员手动启用。

### 2. Jack Dorsey 旗下 Block 发布语音模型 Dessa：只听人声、不经过文字
- 来源：Block 官方 / The Verge / TechCrunch
- 链接：https://block.xyz/dessa
- 这件事是什么：Block 小团队推出 Dessa，全双工「语音进、语音出」，号称完全用人类对话音频从零训练，不走 ASR+LLM+TTS 老路；能同时听和说，带停顿、反讽、笑声等。演示可在 MacBook Pro M4 Max 级机器本地实时跑，目前仍是研究预览，公开 API/权重未开放，优先给 AI 安全研究者内测。
- 为什么重要：支付巨头亲自做「原生语音大脑」，说明语音助手不再只是套壳大模型；逼真度也立刻引发诈骗、深度伪造监管讨论。
- 对我有什么影响：普通用户暂时玩不到，可先听官网样例判断是不是噱头。做客服、外呼、教育产品的，关注「全双工 + 本地」会不会成为新标配，并提前想好鉴伪与用户告知。

### 3. AWS 开源 Agent 运行时 Infinity：等工具时「挂起」Agent，不占算力
- 来源：AWS Open Source Blog
- 链接：https://aws.amazon.com/blogs/opensource/introducing-infinity-a-runtime-for-extreme-agent-concurrency/
- 这件事是什么：10 月 23 日，AWS 与伯克利 Hydro 项目发布 Rust 框架 Infinity（Apache 2.0）。思路像 async：Agent 调用慢工具（编译、等人审批）时保存对话并挂起，结果到了再唤醒；官方示例称空闲 Agent 内存占用约 100KB 级，并探索在 Lambda 等 Serverless 上长跑 Agent。
- 为什么重要：多 Agent、长任务的最大成本往往是「干等还占着进程」；若社区采纳，云厂商 Agent 托管和自建编排的成本模型都会变。
- 对我有什么影响：做 Agent 平台的可先读 GitHub quickstart 做 POC，别指望生产级 SLA——这是早期研究版。Serverless 团队可评估能否用挂起替代常驻 Worker 省钱。

### 4. Cursor Agent 能「玩电脑」：自托管 Mac 上可点 iOS 模拟器做验收
- 来源：Cursor 官方文档 / 社区报道
- 链接：https://cursor.com/docs/cloud-agent/self-hosted/computer-use
- 这件事是什么：Cursor 宣布 Agent 支持 Computer Use：在自托管 Mac/Linux Worker 上点击、输入、截屏，驱动桌面应用；典型场景是写完 iOS 功能后自己在 Simulator 里点一遍。需在 Mac 上 `agent worker --computer-use start`，并给独立应用「Cursor Computer Use」开无障碍和录屏权限。
- 为什么重要：编码 Agent 从「改仓库」延伸到「跑 UI 验收」，和 Claude Code 网页版、各类 E2E 测试 Agent 同向竞争，移动端开发痛点最明显。
- 对我有什么影响：做 iOS/Android 的，若已用 Cursor Cloud Agent，可在自己的 Mac 上开 computer use，减少手工点回归。注意权限只给官方 Helper，别误授给终端；Linux 需自己装 X11 依赖。

### 5. 英伟达发布 Minerva：给「AI 工厂」做全网联调与故障根因分析
- 来源：NVIDIA 官方博客
- 链接：https://blogs.nvidia.com/blog/minerva-platform-infrastructure/
- 这件事是什么：10 月 22–23 日，英伟达推出 Minerva AIOps 平台，把 GPU、网络、存储、调度器（Slurm、Run:ai 等）和训练/推理任务遥测打通，用知识图谱 + ML 做异常检测、根因聚合；内置助手 Sherlock，并支持 MCP 接外部 Agent。目前标注为有限参与的预发布 beta，无公开标价。
- 为什么重要：英伟达继续从卖卡延伸到卖「集群运营软件」；万卡集群里一张卡过热就能拖垮整 job，统一观测是刚需。
- 对我有什么影响：个人开发者无感。管 GPU 集群的 SRE/MLOps 可把它和现有 Prometheus/Grafana 方案对比；采购要走销售，先问清楚和你家硬件、调度栈的集成范围。

### 6. 阿里「千问办公」上架 GLM-5.3 与 DeepSeek V4 Pro：入口开始「模型超市」
- 来源：36氪 / 行业媒体（10 月 24 日集中报道）
- 链接：https://www.qianwen.com/（千问办公入口，以产品内实际模型列表为准）
- 这件事是什么：报道称千问办公在已有 Qwen 旗舰之外，接入智谱 GLM-5.3 与 DeepSeek V4 Pro，用户在同一办公入口切换不同厂商模型；同期国产侧还有腾讯 WorkBuddy、字节 TRAE 等「多模型工作台」路线。
- 为什么重要：当单模型榜单天天变，掌握用户入口的平台用聚合换粘性，模型厂则靠分发换调用量——价格战可能更猛。
- 对我有什么影响：办公场景可「写稿用 A、写代码用 B」而不必开三个账号；注意企业数据是否经各模型方、是否符合合规；免费额度与计费按所选模型分开算。

## 今日重点关注

今天最值得重点关注的是：**月之暗面 K3.1 Pro 把「接近顶尖性能 + 即将开源权重」再次推到台前，同时 Block Dessa、Cursor Computer Use、AWS Infinity 三条线都在回答「Agent 下一步怎么更便宜、更真、更能自己验货」**
